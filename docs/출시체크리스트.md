코드 쪽에서 할 수 있는 것은 **W(2026-09-26)까지 다 했다** — §3 에 근거와 함께 적었다.
남은 것은 **계정 · 키 · 돈 · 기기**가 있어야 하는 일뿐이다. 아래 ①~⑩ 은 순서다 — 앞 단계가 뒤 단계를 막는다.
붙여 넣을 값은 전부 [`플레이콘솔-제출팩.md`](플레이콘솔-제출팩.md)(이하 '제출팩')에 미리 써 뒀다.

## 0. 일정 — 가장 긴 줄은 '비공개 테스트 14일'이다

2023-11-13 이후에 만든 **개인** 개발자 계정은 프로덕션 전에 **테스터 12명 이상이 14일 연속 참여한 비공개 테스트**를

조직 계정은 면제지만 D-U-N-S 번호가 필요하다. 그래서 일정은 대략 이렇다:

## 1. 사장님이 할 일 — 순서대로

### ① Play Console 개발자 계정

- 등록비 $25(한 번) · 신원 확인. 개인이면 ⑧ 이 필수다(위).
- **결제 프로필(판매자 계정)** — 인앱 상품을 팔려면 필요하다. 정산 계좌·세금 정보를 넣는다.
  개인으로 팔 때의 사업자 등록·세금 신고는 세무사에게 확인한다(코드와 무관한 일이라 여기서 판단하지 않는다).

### ② 업로드 키 + GitHub 비밀 4개

- 명령과 비밀 이름은 제출팩 §8. **내가 만들면 안 된다** — 채팅에 찍힌 키는 유출된 키다.
- 넣은 뒤 아무 커밋이나 푸시하면 CI `안드로이드 APK 빌드` 잡의 `catpaw-defense-release-aab` 가 **그 키로** 서명된다
  (잡 로그에 "릴리스 키로 서명한다"). 비밀이 없으면 디버그 키 AAB 가 나오고 Play 가 거부한다 — 사고로 올라갈 일은 없다.
- 키스토어 파일은 저장소 밖 두 곳에 둔다. `*.jks` 는 `.gitignore` 에 있다.

### ③ 연락처 이메일 — 개인 Gmail 을 적으면 R 이 무효가 된다

- 개인정보처리방침과 스토어 등록정보에 **공개로** 뜨는 주소다. GitHub 계정 이름이 이메일 앞부분과 같아서, 그 Gmail 을
  적으면 R(주소에서 아이디 지우기)을 한 이유가 사라진다. **게임용 주소를 따로** 두는 것을 권한다.
- 주소와 시행일(출시일)을 알려 주면 내가 `docs/개인정보처리방침.md` 를 채우고 `node tools/site-build.mjs --privacy` 로
  `site/privacy.html` 을 굽고 사이트 푸터에 건다. 자리표시자가 남아 있으면 도구가 거부한다(exit 1).

### ④ 도메인 — 개인정보처리방침 URL 을 Play 에 넣기 **전에**

- Play 스토어 페이지에는 개인정보처리방침 URL 이 **공개로** 뜬다. 지금 주소(`…github.io/-catpaw-defense/privacy.html`)는
  계정 이름을 그대로 보여 준다. 도메인을 먼저 붙이면 이게 안 샌다.
- 할 일: 도메인을 산다(`.com` 연 1~2만원) → DNS 에 **A 레코드 넷**(`185.199.108.153` · `.109.153` · `.110.153` · `.111.153`)을
  **apex(`@`)** 에. `www` 에 CNAME 으로 붙이면 DNS 조회에 계정 이름이 남는다.
- 그 뒤 코드는 `web/js/build.js` 의 `FULL_APP_URL` 한 줄 + `site/CNAME` — 도메인을 알려 주면 내가 한다([`확장가이드.md` §17](확장가이드.md)).
- 주의: 주소가 바뀌면 브라우저판(PWA)은 다른 앱이 된다 — 홈 화면에 깔아 둔 사람은 다시 깔아야 한다. APK 는 상관없다.

### ⑤ Play Console — 앱 만들기와 등록정보 (복사·붙여넣기)

| 칸 | 어디서 |
|---|---|
| 앱 이름 · 기본 언어 · 게임 · 무료 | 제출팩 §1 |
| 짧은·자세한 설명 (한국어 + 영어) | [`스토어-등록문안.md`](스토어-등록문안.md) 그대로 |
| 스크린샷 8장(1080×1920) · 기능 그래픽 · 아이콘 512 | 제출팩 §2 — `store/` |
| 콘텐츠 등급(IARC) | 제출팩 §5 — 확률형 아이템 **있음** · 디지털 구매 **있음** |
| 데이터 보안 | 제출팩 §6 — 수집·공유 없음. Play 결제 라이브러리에 대한 근거도 거기 |
| 대상 연령 · 광고 · 앱 액세스 | 아동 대상 아님 · 광고 없음 · 로그인 없음(모든 기능 접근 가능) |
| 개인정보처리방침 URL | ③④ 뒤 |

### ⑥ 내부 테스트 트랙 — 첫 업로드

- ② 뒤 CI 가 만든 `catpaw-defense-release-aab` 의 `.aab` 를 올린다. 버전 1.0.0 (versionCode 10000).
- Play 앱 서명은 기본값(Google 이 앱 서명 키를 만든다)으로 둔다.
- 다시 올려야 하면 `node tools/bump-version.mjs patch` — 같은 versionCode 는 두 번 못 올린다(§5).

### ⑦ 인앱 상품 9개 + 라이선스 테스트

- AAB 가 한 번 올라가야 상품 메뉴가 열린다. 상품 ID 는 제출팩 §3 의 **sku** 그대로 — 글자 하나까지.
- 설정 → 라이선스 테스트에 본인·테스터 Gmail 을 넣고, 내부 테스트로 깔아 [`결제연동.md`](결제연동.md) 맨 아래 체크리스트를 돈다.
  특히 **결제 시트가 닫히자마자 강제 종료 → 다시 켜면 캣닢이 정확히 한 번 들어오는지** — W 에서 순서를 바꾼 자리다.

### ⑧ 비공개 테스트 — 12명 · 14일 연속

- 비공개 테스트 트랙에 테스터 12명 이상(안드로이드 폰 + 구글 계정)을 넣는다. 테스터는 옵트인 링크로 참여하고 Play 에서 깐다.
  중간에 나갔다 들어오면 14일을 다시 센다.
- **W 전에 사이트에서 받은 앱**(홈 화면 이름에 '(사이트)' 가 없는 '캣포 디펜스')이 깔린 폰은 그걸 먼저 지워야 Play 판이 깔린다 —
  서명이 달라 덮어쓰기가 안 된다. W 뒤 사이트판은 다른 앱 id 라 나란히 깔린다.
- 이 기간에 §2(기기 확인)를 테스터들과 돈다. 고칠 게 나오면 고쳐서 새 AAB 를 같은 트랙에 올린다.
  (새 빌드를 올려도 테스터가 참여 중이면 기간이 이어지는 것으로 안다 — 대시보드의 카운터로 확인한다.)

### ⑨ 프로덕션 액세스 신청

14일이 차면 대시보드에서 신청한다. 테스트를 어떻게 했는지 묻는 질문에 §2 의 결과와 고친 것을 적는다.

### ⑩ 프로덕션 출시

- **단계적 출시**(10~20%)로 시작 → Android vitals(크래시·ANR)를 본다 → 100%.
- `git tag v1.0.0 && git push --tags` — `release.yml` 이 사이트판 APK 를 태그 릴리스로 올린다.
- 광고·홍보물(SNS 게시물 포함)에는 **"확률형 아이템 포함"** 을 표시한다(게임산업법 — 게임 안·홈페이지는 이미 됐다).
- 출시 뒤 고를 것: 사이트의 다운로드 버튼을 Play 링크로 바꿀지(사이트판은 Play 없는 기기용으로 남길 수 있다) ·
  저장소를 Private 으로 바꿀지(제출팩 §9 — 바꾸는 순간 GitHub Pages 가 끊기는 조건이 있다).

## 2. 기기 확인 — 설치 뒤 (내가 못 하는 유일한 검사)

> 까는 방법은 [`실기기설치.md`](실기기설치.md). 콘솔은 **디버그 APK** 에서만 `chrome://inspect` 로 보인다.

- [ ] 첫 실행: 로딩 → 탭 → 출석 시트 → 타이틀. 콘솔 에러 0
- [ ] **뒤로가기 (W 에서 고쳤다)**: 전투 중엔 일시정지 열기/닫기 · 맵/챕터 목록에선 타이틀 · 타이틀에선 앱이 뒤로 간다(홈 화면).
      그리고 **한 번 내렸다 다시 열어서 전투 중 뒤로가기** — 여전히 일시정지가 떠야 한다. W 전에는 여기서 앱이 그냥 내려갔고,
      타이틀에서는 화면을 옮긴 만큼 눌러야 내려갔다
- [ ] **홈 버튼·전화 (W)**: 전투 중 홈으로 갔다 오면 일시정지 상태로 돌아온다(전에는 그대로 흘러 목숨이 깎였다)
- [ ] **진동 (W)**: 설정에서 진동을 켜면 실제로 떨린다. W 전 APK 에는 진동 권한이 없어 설정과 상관없이 안 떨렸다
- [ ] 몰입 모드: 상태바·내비게이션 바가 숨고 쓸어내리면 잠깐 나온다
- [ ] **펀치홀 카메라 폰**: 상단 HUD(목숨·골드·웨이브)가 카메라 구멍에 가리지 않는다 — 웹은 safe-area 를 쓰지만
      WebView 가 그 값을 주는지는 기기에서만 보인다
- [ ] 결제 — ⑦ 의 체크리스트. 사이트판에서는 상점이 '결제 준비 중' 으로 뜨는 게 맞다(Play 에 없는 앱 id)
- [ ] 사이트판과 Play 판이 나란히 깔린다(홈 화면에 '캣포 디펜스' 와 '캣포 디펜스 (사이트)')
- [ ] 앱을 껐다 켜도, 업데이트해도 진행도가 남는다 · 백업 복원(설정 → 백업 → 새 기기)
- [ ] **저사양 폰 30웨이브 프레임률** — W 에서 헤드리스로 CPU 를 4·6배 느리게 해서 쟀다: 마왕전(만렙 고양이 18마리)의
      게임 로직·HUD 가 프레임당 5.6ms(4배)라 여유가 있고, HUD 가 매 프레임 레이아웃을 돌리던 것(4배에서 4.3ms)은 고쳤다.
      **캔버스 그리기는 폰에서 GPU 가 해서 여기서 못 잰다** — 가장 싼 폰 하나로 마왕전까지 가 본다
- [ ] 가로 회전(태블릿·폴더블): 깨지지는 않지만 지도가 작아 사실상 못 논다 — 알고 가는 한계(§4)

## 4. 알고 가는 한계 (숨기지 않는다)

- **서버가 없다.** 영수증 위조를 못 막고, Play 에서 환불돼도 이미 준 것을 회수하지 못한다([`결제연동.md`](결제연동.md) §4).
  매출이 생기면 계정·서버 검증이 먼저다.
- **캔버스 프레임률은 실기기 확인 전이다**(§2).
- **가로 레이아웃이 없다.** Android 16 은 큰 화면에서 세로 고정을 무시한다 — 태블릿에서는 작게 뜬다.
- **진행도 옮기기가 없다.** 폰을 바꾸면 Android 백업에 기댄다. 사이트판 ↔ Play 판, 브라우저판 ↔ 앱도 안 옮겨진다.
- **새벽 능선의 열린 문제 둘**(어둠 도배 100% · 잡몹 순서)은 안 고쳤다 — [`속성과카드.md`](속성과카드.md).
- **영어 문구는 원어민 감수 전**이다(게임·스토어 둘 다).
- **상점의 청약철회 문구는 초안**이다 — 법률 검토를 권한다.
- **Android 개발자 인증**: 2026-09-30 브라질·인도네시아·싱가포르·태국부터, 2027 년 전 세계로 넓어질 예정이다. Play 판은 Play 가
  처리하지만, 사이트판 APK 는 그때 인증된 개발자 등록이 필요해질 수 있다.

## 5. 버전 규율 — 배포마다

- `node tools/bump-version.mjs patch`(또는 minor/major) — `package.json` · `web/js/version.js` · `android/app/build.gradle.kts` ·
  `web/sw.js` · `site/index.html` 다섯 곳이 함께 오른다. `version.test` 가 대조한다.
- `versionCode` 는 `x.y.z → x*10000 + y*100 + z`. 같은 버전을 다시 올려야 하면(리젝 뒤) `CATPAW_VERSION_CODE` 로 versionCode 만 올린다.
- 브라우저판(`site/play/`)은 캐시 이름에 구운 내용의 지문이 붙어 저절로 갈린다. APK 와 전체판은 이 규율을 따른다.
- 확률 표(`gacha.js`)를 고쳤으면 `node tools/site-build.mjs --odds-only` 로 사이트 확률 페이지도 다시 굽는다(`site.test` 가 잡는다).
