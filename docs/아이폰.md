# 아이폰

**아이폰용 앱은 없다.** 대신 브라우저에서 도는 **데모 빌드**가 있고, 그게 아이폰의 유일한 길이다.

<https://kimd10041004-gif.github.io/-catpaw-defense/play/>

---

## 1. 왜 앱이 없나

`ios/` 도 Xcode 프로젝트도 스위프트 한 줄도 없다. 만들려면 두 가지가 필요한데 둘 다 여기 없다.

| 필요한 것 | 왜 |
|---|---|
| **맥** | Xcode 가 맥에서만 돈다. 안드로이드는 리눅스 CI 에서 공짜로 컴파일되는데(`ci.yml`) 아이폰은 그게 안 된다 |
| **애플 개발자 계정 (연 $99)** | 없으면 서명이 7일마다 만료돼서 일주일에 한 번씩 다시 깔아야 한다 |

APK 는 아이폰에 **못 깐다**. 확장자를 바꿔도, 사이드로드 도구를 써도 안 된다 — 안드로이드 실행 파일 형식이다.

## 2. 그래서 웹앱(PWA)

게임이 웹 기술로 만들어져 있어서 사파리에서 그대로 돈다. 아이폰용 배선은 이미 코드에 들어 있다.

```
사파리로 https://kimd10041004-gif.github.io/-catpaw-defense/play/ 를 연다
→ 아래 공유 버튼 → 홈 화면에 추가
→ 주소창 없이 앱처럼 뜬다. 한 번 받아 두면 비행기 모드에서도 돈다
```

| 코드 | 하는 일 |
|---|---|
| `apple-mobile-web-app-capable` (`web/index.html:9`) | 주소창 없는 앱 화면 |
| `apple-touch-icon` (`:15`) | 홈 화면 아이콘 |
| `viewport-fit=cover` + `env(safe-area-inset-*)` 9곳 | 노치와 홈 인디케이터를 피해 그린다 |
| 서비스 워커 (`web/sw.js`) | 오프라인 |
| 첫 터치의 `audio.unlock()` (`main.js:109` 외) | iOS 는 사용자 조작 전엔 소리를 안 낸다 |

크롬이든 사파리든 상관없다 — 아이폰의 모든 브라우저는 속이 사파리(WebKit)다.

## 3. 데모에는 무엇이 있고 무엇이 없나

**있다** (무료 범위 전부):
자유 모드 6맵 · 시나리오 1~2막 18장 · 도전 5종 · 펫 · 훈련 · 무한 모드 · 주간 도전 · 도감 · 업적 · 출석.

**없다**: 시나리오 3막(19~24장) · 도전 팩 2(5종) · 스킨 팩(8종) · 결제.

**잠가 둔 게 아니라 파일이 없다.** `tools/demo-build.mjs` 가 `content/index.js` 의 `// demo:strip` 줄과
그 파일들을 빼고 굽고, `domain/shop.js` 의 상품 목록을 빈 배열로 갈아 끼운다.
`tests/node/demo.test.mjs` 가 **구운 결과를 열어** 유료 id 가 한 글자라도 남았는지 본다.

왜 이렇게까지 하나: 그냥 `web/` 을 올리면 웹의 '데모 결제'가 성공해서 3막·스킨 팩이 **공짜로 열린다.**
파는 물건을 나눠 주는 셈이다. 잠그기만 하면 파일은 여전히 딸려 가고, 잠금은 브라우저에서 풀린다.

상점을 열면 캣닢 소모품(게임 안에서 모은 캣닢으로 사는 것)은 그대로 있고, 그 아래
"전체판 — 안드로이드 앱 받기" 한 칸이 있다. 결제 시도는 `DisabledBillingProvider` 가 그 자리에서 거절한다.

## 4. 안드로이드와 다른 넷

고쳐서 되는 게 아니라 iOS 사파리의 한계다.

1. **상태바가 겹친다.** iOS 는 `display: fullscreen` 을 모른다 — `standalone` 까지다.
   시계·배터리가 반투명으로 얹힌다. 안전 영역으로 피해 그리니 가려지지는 않는다.
2. **회전 잠금이 안 걸린다.** 매니페스트의 `"orientation": "portrait"` 를 iOS 가 무시한다.
   그래서 가로로 눕히면 **"세로로 돌려 주세요" 막**이 뜬다(`web/css/style.css` 끝) —
   기준은 잰 값이다: 타일 = (높이 − 190) / 14 이라 높이 560px 아래면 26px 밑으로 떨어진다.
   아이폰 가로는 14.5px 이고 손가락은 44px 다. 그래도 하겠다면 '이대로 하기'가 있다.
3. **설치를 손으로 해야 한다.** 안드로이드 크롬처럼 "설치하시겠습니까"가 안 뜬다.
4. **진동이 없다.** `navigator.vibrate` 를 사파리가 지원하지 않는다.
   `main.js:536` 이 미리 막아 둬서 오류는 안 나고, 그냥 안 떨린다.

## 5. 세이브는 안 넘어간다

브라우저판은 브라우저 저장소, 안드로이드 앱은 WebView 저장소에 진행도를 둔다. 서버가 없으니 **옮길 방법이 없다.**
데모로 1~2막을 깨고 앱을 깔면 처음부터다. 사파리 방문 기록을 지우면 데모 진행도도 같이 사라진다.

## 6. 내가 만들 때 하는 일

```bash
node tools/demo-build.mjs        # web/ → site/play/  (유료 콘텐츠 빼고)
node --test tests/node/demo.test.mjs
```

산출물은 **커밋하지 않는다**(`.gitignore`) — `web/` 을 그대로 복사한 것이라 저장소가 두 배가 된다.
`.github/workflows/pages.yml` 이 배포 직전에 굽는다. `web/**` 을 고치면 그 워크플로가 저절로 돈다.

새 유료 콘텐츠를 만들 때는 **파일을 따로 만들고** `content/index.js` 의 import 줄 끝에 `// demo:strip` 을 붙인다.
무료 파일에 섞어 넣으면 `demo.test` 가 빨개진다 — 그게 이 검사의 목적이다.

## 7. 아직 안 한 것 (하려면)

- **진짜 iOS 앱.** 맥과 개발자 계정이 생기면 `Capacitor` 나 `WKWebView` 래퍼로 `android/` 와 같은 구조를 만들 수 있다.
  결제는 Google Play 대신 StoreKit 이라 `BillingBridge` 를 하나 더 써야 한다(`docs/결제연동.md` 와 같은 모양).
- **세이브 옮기기.** 서버가 없어서 지금은 못 한다. 코드를 문자열로 뽑아 붙여 넣는 방식이면 서버 없이도 되지만
  이번 범위 밖이다.
- **원어민 감수.** 영어는 내가 썼다(`docs/확장가이드.md` §16).
