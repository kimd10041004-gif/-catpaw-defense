# 스토어 등록 문안 (Play Console) — 초안

Play Console 에 붙여 넣을 글이다. **숫자는 손으로 안 적었다** — 뽑기 확률은 `gacha.js` 의 `disclosureRows()` 가
게임 화면에 그리는 값 그대로이고, 무료 범위 약속은 README 의 문장 그대로다. `tests/node/store-listing.test.mjs` 가
이 파일의 숫자·문장이 코드·README 와 같은지 본다. 코드를 고치면 여기도 빨개진다 — 스토어에 거짓말이 올라가지 않게.

> **아직 안 정해진 것**: 개인정보처리방침 URL(`[연락처]`·`[출시일]` 이 비어 있다) · 도메인(R). 둘 다 사장님 몫이다.
> 영어는 원어민 감수 전이다(README 영어 지원 절).

## 3. 전체 설명

### 한국어

집에 해충이 몰려온다. 고양이 열다섯 마리를 길목에 세워 막는다.

**모드 여섯**
- 시나리오 — 컷신으로 이어지는 24장. 장마다 주 목표 하나와 부 목표 둘, 별 최대 3개
- 자유 모드 — 맵 7개를 골라 30웨이브 끝까지. 다 막으면 무한 모드로 표 밖까지
- 도전 — 골드 절반, 공중만, 맨손, 목발 없이… 규칙 하나가 판을 바꾼다
- 주간 도전 — 같은 주엔 모두가 같은 판
- 속성 원정 — 여섯 칸을 목숨 하나로. 덱은 네 마리
- 훈련 — 캣닢으로 고양이를 영구히 키운다

**고양이 15종 · 해충 17종 · 보스 8종**
고양이마다 사거리·표적·능력이 다르고 3레벨까지 키운다. "더 센 고양이"가 아니라 "다른 고양이"다 — 어떤 고양이도 다른 고양이의 상위 호환이 아니다. 보스는 등급이 오를수록 패턴이 는다.

**속성 6종 — 흙 · 번개 · 얼음 · 불 · 어둠 · 빛**
고양이에게 속성 룬을 끼워 상성을 맞춘다. 속성 원정에서는 여섯 칸이 여섯 속성이라 한 가지로 도배하면 막힌다.

**필살기 6종 — 손가락으로 직접 터뜨린다**
넷을 골라 들고 들어간다. 쓸수록 세지고 쿨다운이 준다.

**무료 범위 (약속)**: 자유 모드 7맵 · 시나리오 1~2막(18장) · 도전 7종 · 펫 · 훈련 · 필살기 로드아웃·성장 · 무한 모드 · 주간 도전.
결제 없이 전 맵을 클리어할 수 있게 설계했고, 그 조건은 검사가 지킨다.
**유료**: 시나리오 3막(19~24장, 새 웨이브 구성 2개) · 도전 팩 2(규칙 5) · 스킨 팩(겉모습만, 능력치 없음) · 스타터 팩.
유료 콘텐츠는 무료 콘텐츠를 잠그지 않고, 유료 전용 타워·맵·보스는 없다.

**뽑기 — 확률을 공개한다**
캣닢으로 돌리는 뽑기가 있다(캣닢은 플레이로도 모이고 결제로도 산다). 등급별 확률은 아래와 같고, 게임 안 뽑기 화면에도 같은 표가 있다.

| 등급 | 확률 |
|---|---|
| 전설 (새 고양이 — 가장 드물다) | 2.00% |
| 희귀 (새 고양이) | 10.00% |
| 속성 룬 (여섯 중 하나가 고르게) | 38.00% |
| 카드 조각 (모아서 원하는 카드로) | 50.00% |

1회 60 캣닢 · 10연 540 캣닢. **10연은 상위 등급(희귀 이상)을 하나 보장한다.**

- 광고 없음 · 인터넷 권한 없음 · 서버 없음 (진행도는 기기 안에만 있다)
- 한국어 · 영어

### English

Pests are coming for the house. Line up fifteen cats along the path and hold them off.

**Six modes**
- Story — 24 chapters linked by cutscenes. One main goal and two side goals per chapter, up to three stars
- Free play — pick one of 7 maps and survive all 30 waves. Clear them all and Endless mode goes past the table
- Challenges — half gold, air only, bare paws, no crutch… one rule changes the whole run
- Weekly challenge — everyone gets the same run in the same week
- Element Expeditions — six stages on a single life, with a deck of four
- Training — spend catnip to grow a cat for good

**15 cats · 17 pests · 8 bosses**
Every cat has its own range, targeting and ability, and grows through 3 levels. Not stronger cats, different cats — no cat is a strict upgrade of another. Bosses gain patterns as their rank rises.

**6 elements — earth · bolt · ice · fire · dark · light**
Slot an element rune into a cat to match the enemy. In Element Expeditions the six stages are six elements, so stacking one element gets you stuck.

**6 specials — you set them off with your finger**
Pick four to bring in. They get stronger and cool down faster the more you use them.

**Free range (our promise)**: 7 free-play maps · Story acts 1–2 (18 chapters) · 7 challenges · pets · training · special loadout and growth · Endless mode · weekly challenge.
The game is designed so every map can be cleared without paying, and a test enforces that condition.
**Paid**: Story act 3 (chapters 19–24, 2 new wave layouts) · Challenge pack 2 (5 rules) · skin packs (looks only, no stats) · starter pack.
Paid content never locks free content, and there are no paid-only cats, maps or bosses.

**Gacha — odds are public**
There is a draw you spin with catnip (catnip is earned by playing and can also be bought). Odds per tier are below, and the same table is shown on the draw screen in the game.

| Tier | Odds |
|---|---|
| Legendary (new cat — rarest) | 2.00% |
| Rare (new cat) | 10.00% |
| Element rune (one of six, evenly) | 38.00% |
| Card shards (collect to pick a card) | 50.00% |

60 catnip per draw · 540 for a 10-draw. **A 10-draw guarantees at least one Rare or better.**

- No ads · no internet permission · no server (progress stays on the device)
- Korean · English

## 5. 데이터 안전 양식 — 답

| 문항 | 답 | 근거 |
|---|---|---|
| 데이터를 수집하나 | **아니오** | 서버가 없다. 진행도는 기기의 localStorage 에만 있다 |
| 데이터를 공유하나 | **아니오** | 외부로 보내는 코드가 없다. 인터넷 권한도 없다 |
| 전송 중 암호화 | 해당 없음 | 전송이 없다 |
| 삭제 요청 방법 | 해당 없음 | 서버에 아무것도 없다. 앱을 지우면 끝이다 |
| 결제 정보 | Google Play 결제가 처리한다 | 앱은 영수증 토큰만 본다 |
