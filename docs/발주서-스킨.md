# 그림 스킨 발주서 — 3장

지금 스킨 11종은 전부 색 필터다(그림 없이 판다). 이 발주서는 **그림으로 그리는 스킨** 3장이다. 그림이 오면
`web/js/framesets.js` 에 `registerFrameSet` 한 줄, `web/js/content/skins.js` 의 `look` 을 `{ frames }` 로 한 줄 — 코드는 그게 전부다.

## 규격 (원본과 같아야 한다 — validateAll 이 대조한다)

| 항목 | 값 |
|---|---|
| 형식 | PNG, 투명 배경, 가로 스트립 |
| 칸 | **5칸 × 169×169px** (총 845×169) — 치즈냥·샴냥·검은냥 원본(`CAT`)과 같은 격자 |
| 몸 상자 | 칸 중심 (82, 73), 높이 107px — 원본 `body: { cx: 82, cy: 73, h: 107 }` 과 같게 |
| 방향 | 효과(앞발·칼·룬)는 **전부 오른쪽**을 본다 — 왼쪽 타깃은 코드가 통째로 반전한다 |
| 그림자 | 넣지 않는다 — 코드가 그린다 |
| 파일 이름 | `web/art/cat-cheese-armor.png` · `cat-siamese-wizard.png` · `cat-black-pirate.png` |

프레임 5칸 (원본 `tools/art-spec.mjs` 의 CAT_FRAMES 와 같다):

| 칸 | 뜻 | 메모 |
|---|---|---|
| ① 발사 순간 | 앞발이 가장 뻗은 순간 | 무기·효과가 가장 크게 |
| ② 되돌아옴 | 되돌아오는 중 | |
| ③ 거의 제자리 | 거의 원래 자세 | |
| ④ 대기 | 가장 오래 보이는 칸 | 이 칸이 상점 카드·도감에 쓰인다 |
| ⑤ 자는 중 | 베개·이불까지 | 오래 안 쏘면 |

## 세 장

1. **갑옷 치즈냥** (`cheese-armor`) — 치즈냥의 실루엣·색을 지키고 가벼운 가죽 갑옷 + 작은 방패. 앞발 잽은 그대로.
   등록: `registerFrameSet('cat-cheese-armor', { src: 'art/cat-cheese-armor.png', ...CAT })`, 스킨 `look: { frames: 'cat-cheese-armor' }`, `sku: 'skin_pack_3'`(새 상품).
2. **마법사 샴냥** (`siamese-wizard`) — 뾰족 모자 + 지팡이. 샴냥의 눈빛(코드가 덧그리는 `effectOverArt`)은 그대로 살린다 — 눈 위에 그림을 얹지 않는다.
   등록: `registerFrameSet('cat-siamese-wizard', { src: 'art/cat-siamese-wizard.png', ...CAT })`.
3. **해적 검은냥** (`black-pirate`) — 안대 + 삼각모, 칼은 원본 위치(오른쪽). 저격 자세 유지.
   등록: `registerFrameSet('cat-black-pirate', { src: 'art/cat-black-pirate.png', ...CAT })`.

## 받은 뒤 할 일

1. `tools/slice-sheet.mjs` 로 배경을 파내 스트립으로 굽는다(알파 없는 시트로 올 때).
2. `framesets.js` 등록 → `skins.js` 의 `look` 교체 → `npm test`(격자 검사) → `tools/screenshot.mjs`(스킨 장착 픽셀 검사).
3. `web/sw.js` ASSETS 에 새 png 3장 추가(`sw.test` 가 빠지면 잡는다) → `node tools/bump-version.mjs patch`.
